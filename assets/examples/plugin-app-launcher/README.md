# 悬浮快捷启动（app_launcher）1.2.0

登录后悬浮图标打开本机软件。每人独立入库。打开动作走 **本机隐藏助手**（Win EXE / Mac App），只绑定当前登录用户。

## 安装插件

上传 `app_launcher-1.2.0.zip` → 启用 → **软件设置 → 快捷启动**

## 本机助手（必装才能点开软件）

1. 设置页下载 **Windows 助手** 或 **Mac 助手**
2. Windows：解压后双击 `install.bat`（开机自启、无窗口）
3. Mac：解压后运行 `install.sh`（开机自启、无 Dock 图标）
4. 回到设置页点 **绑定当前账号**

之后网页点击快捷方式，只给你这台电脑、这个账号发「打开 + 路径」。A 用户点了不会打开别人的电脑。

助手监听 `127.0.0.1:18791`，也可轮询监控台队列（需已绑定）。
