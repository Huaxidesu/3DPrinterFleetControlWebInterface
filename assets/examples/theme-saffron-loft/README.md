# 藏红工坊（saffron_loft）

`siteMode: full` 整站主题：与默认侧栏 + 方卡网格完全不同。

## 设计

| 维度 | 默认 / 常见 | 本主题 |
|------|-------------|--------|
| 壳层 | 左侧栏 + 顶栏 | **底部胶囊导航** + 顶部品牌胶囊 |
| 设备卡 | 直角深色方卡 | **票券卡**：不对称圆角、左侧色轨、斜角 TICKET |
| 配色 | 蓝灰 / 青霓虹 HUD | **深焙咖啡 + 藏红 + 薄荷** |
| 字体 | 系统默认 | **Fraunces + Figtree** |
| 动效 | 几乎静止 | 光球漂移、卡片错落入场、进度条扫光、LIVE 脉冲 |
| 登录 | 居中表单 | 左氛围右准入双栏 |

## 配色套

- `loft_night` 夜工坊（默认）
- `loft_ember` 余烬

## 安装

打 ZIP（根目录含 `theme.json`）→ **软件设置 → 主题** 上传启用。
