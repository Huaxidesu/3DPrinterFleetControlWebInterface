# 详情控制台（detail_console）v1.4.2

替换设备详情抽屉内的控制区：

- **顶部摄像头**（多路可左右滑动 / 箭头切换，含第三方摄像头）
- 会挂载 `device.detail.camera.after` 槽位（例如 `extra_cameras` 设置面板）
- 喷头 / 热床 / 腔温、风扇、速度、LED
- XY 圆盘 + 热床 Z 行 + 挤出机进退（**点动走宿主 `jog`**）
- 暂停 / 恢复 / 取消 / 急停 / 设温
- **料盘**：Mainsail 纸盘 SVG（`spool.svg`）

## 料盘规则

- **有 AMS、槽位带打印机颜色**：显示该颜色，料盘按满盘画。绑定耗材管理后，余量改用绑定料卷的 `remainGrams / 容量`。末尾额外显示 **外挂** 料盘（默认空，绑定后才有颜色/余量）。
- **不能读颜色的机器**（Klipper 单色等）：默认空盘 +「空」。绑定耗材管理后才显示料卷颜色和余量。
- 点选料位 → 选择本地料卷 → **绑定**。

## 安装

打 ZIP（根含 `plugin.json`）→ 软件设置 → 插件 → 上传 → 启用。
