# 机型肖像卡片（plugin）

按设备 **机型** 从免费图库（Openverse / Wikimedia，无需 API Key）匹配产品图，并重排设备卡片顶部肖像区。

- **无设置页**（安装启用即可）
- **机型一致性**：只采用标题/文件名明确包含所设机型（及别名）的结果；匹配不上则用默认图，避免乱图
- **未设置机型** → 内置透明默认图 `static/default.svg`
- 仅占用槽位 `device.card.before`，不覆盖其它插件的 `after-name` / `temps` / `extra` / `footer`

## 安装

将本目录打成 ZIP（根目录含 `plugin.json`），在 **软件设置 → 插件** 上传并启用。

## 说明

机型字段来自设备 `model`（添加/编辑设备时可填）。请尽量写完整机型名（如 `P1S`、`X1 Carbon`、`K1 Max`）。

图源结果会缓存约 7 天；升级匹配规则后会自动忽略旧缓存。外网不可达或找不到对应机型图时回退默认图。
