巡查派单（farm_dispatch）1.0.1

【一句话】
监控台侧栏内使用：巡查看板、派单审核、提交打印、派单日志；按机型·材料·颜色智能派单；不可用设备禁止开打。

【重要变更 1.0.1】
不再用独立浏览器窗口（/farm/* 会卡死）。四个页面都在侧栏打开，UI 跟监控台其它插件页一致。

【侧栏入口】
1. 巡查看板 — 报错/完成、设空闲·维修、绑耗材、换料通知
2. 派单审核 — 通过派单 / 驳回写原因
3. 提交打印 — 上传机型·材料·颜色·G-code
4. 派单日志 — 全部操作记录

【安装】
1. 上传 farm_dispatch-1.0.1.zip → 启用
2. 软件设置 →「巡查派单」→ 初始化用户组
3. 用户管理：账号加入「巡查」「审核」「派单申请」
4. 侧栏点击对应菜单（需有对应权限/用户组）

【开打拦截】
维修 / 报错未确认 / 完成未确认 / 打印中 / 离线 / 未绑耗材 → 禁止发文件（含其它插件）。
