# FDM 机群紧凑卡片（plugin）v1.0.3

保留原 FDM 设备卡片全部功能；工具栏提供切换图标，进入超紧凑机群视图，一屏可排布数百台。

## 功能

- **切换**：FDM 页工具栏「机群紧凑 / 原卡片」
- **紧凑卡片**：打印机名、喷头/热床温度、进度条、剩余时间
- **完成盖章**：打印完成后透明「完成」章；报错时盖「报错」章
- **语音播报**：完成播报「{设备名}打印完成」，报错播报「{设备名}报错」（可关）。浏览器需先点一次喇叭按钮解锁声音。
- **点击卡片**：打开原来的设备控制面板（抽屉）

## 插件变量

| 变量 | 说明 |
|------|------|
| `voice_announce` | 完成/报错语音（默认开） |
| `default_compact` | 进入 FDM 页默认紧凑（默认关） |

## 安装

打 ZIP 后在 **软件设置 → 插件** 上传启用。仅影响 FDM 设备区，光固化不受影响。
